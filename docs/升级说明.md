# AooBee 项目升级与技术说明

## 1. 项目目标

本项目已完成从远程数据库配额问题导致的首页 500 错误，转为基于本地 Docker PostgreSQL 的稳定开发与内容生成流程。

## 2. 当前已完成的升级

### 2.1 本地数据库切换
- 使用 Docker Compose 启动 PostgreSQL 容器
- 通过 Prisma 连接本地数据库
- 避免依赖远程数据库配额限制

### 2.2 首页与分类页容错
- 首页在数据库异常时不会直接崩溃
- 通过兜底内容展示，保证页面仍可访问

### 2.3 内容本地化
- 已完成分类、产品、文章、FAQ 的本地种子数据初始化
- 文章详情页已可显示正文内容

### 2.4 SEO/GEO 页面支持
- 自动生成 sitemap、robots、llms.txt
- 支持结构化数据 JSON-LD

## 3. 关键技术栈

- Next.js 16
- React 19
- TypeScript
- Prisma 7
- PostgreSQL 16
- Docker Compose
- Tailwind CSS 4

## 4. 本地开发流程

```bash
# 1. 启动数据库
docker compose up -d

# 2. 安装依赖
npm install

# 3. 启动开发页
npm run dev

# 4. 初始化内容
npx tsx scripts/seed.ts
npx tsx scripts/seed-articles.ts
```

## 5. 常见问题

### 5.1 数据库连接失败
检查环境变量和 Docker 是否已启动：
```bash
docker compose ps
docker compose logs db
```

### 5.2 页面显示空白或部分内容
确认本地种子数据已写入：
```bash
npx tsx scripts/seed.ts
npx tsx scripts/seed-articles.ts
```

### 5.3 文章正文不显示
确认文章内容字段已落库，并检查页面渲染逻辑。
