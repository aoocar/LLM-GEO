# 手动修改网站前端展示内容教程

> ⚠️ **已废弃**：本文档描述的是「数据库 + 种子脚本」旧模型。md 化重构后内容源已改为 `content/` 下的 Markdown 文件。请改用新教程：**`docs/使用教程.md`**。

这份教程说明如何手动修改当前站点前端展示的内容，包括首页文字、分类页内容、推荐/指南/对比页面内容，以及分类、产品和文章的数据。

---

## 1. 先理解当前结构

当前项目是“前端页面组件负责展示，内容数据来自数据库”。

也就是说：

- 页面文字、标题、按钮文案等，通常写在页面组件文件里。
- 分类、产品、文章、推荐内容等，通常保存在数据库中。

因此，修改内容时分两类：

1. 修改页面文案：改前端组件文件。
2. 修改展示数据：改数据库中的分类、产品、文章内容。

---

## 2. 修改首页文案

文件位置：
- [src/app/page.tsx](src/app/page.tsx)

这个文件控制首页的主要展示内容，包括：

- Hero 区域标题
- Hero 区域副标题
- 搜索框占位文案
- 热门搜索词
- 分类区标题
- 产品区标题
- SEO 说明文案

### 示例

你可以把下面这段：

```tsx
<h1 className="text-3xl md:text-5xl font-bold tracking-tight">
  发现各行业最佳产品与服务
</h1>
```

改成你想要的标题，例如：

```tsx
<h1 className="text-3xl md:text-5xl font-bold tracking-tight">
  发现更适合你的行业产品与服务
</h1>
```

## 3. 修改分类页内容

文件位置：
- [src/app/(directory)/[category]/page.tsx](src/app/(directory)/[category]/page.tsx)

这个页面控制：

- 分类页的 h1 标题
- 分类描述文字
- 产品推荐区标题
- FAQ 区标题

### 你可以修改的重点

- 分类名称和描述：需要改数据库里的 category 数据
- 页面上方标题文案：改组件里的 JSX
- 产品列表标题：改 `ProductList` 的 `title`
- FAQ 标题：改 `FaqSection` 的 `title`

### 示例

```tsx
<h1 className="text-3xl font-bold text-gray-900">{cat.name}</h1>
<p className="text-gray-600 max-w-3xl">{cat.description}</p>
```

如果你想让分类页显示更像“某个行业官网”，可以把这里的文案替换成更正式的版本。

### 推荐页

### 对比页

### 指南页
文件位置：
- [src/app/(content)/guide/page.tsx](src/app/(content)/guide/page.tsx)

这些页面负责：

- 页面主标题
- 页面副标题
- 页面介绍文案
- 文章卡片展示
- 标签文案（如“行业指南”“对比分析”“最佳推荐”）

### 示例

在 [src/app/(content)/guide/page.tsx](src/app/(content)/guide/page.tsx) 里，可以修改：

```tsx
<h1 className="text-3xl font-bold text-gray-900">行业指南</h1>
<p className="mt-2 text-gray-500">
  专业行业分析、产品评测、对比指南和使用教程，助您做出明智选择。
</p>
```

这会直接影响“指南”页面的显示文案。

## 6. 修改分类、产品、文章数据（最常用）

### 6.1 修改分类数据

分类数据在数据库的 `Category` 表中。你可以通过以下方式来改：

- 直接用数据库工具修改
- 或者修改种子脚本后重新执行

种子脚本文件：
- [scripts/seed.ts](scripts/seed.ts)

这个文件里包含：

- 分类列表
- 产品列表
- 文章列表

### 6.2 修改产品数据

产品数据在数据库的 `Product` 表中，包含：

- 名称
- 描述
- 价格
- 评分
- 评价数量
- 所属分类

### 6.3 修改文章数据

文章数据在数据库的 `Article` 表中，包含：

- 标题
- 摘要
- 正文
- 关键词
- metaTitle
- metaDesc
- FAQ 内容

## 7. 用种子脚本批量修改内容

如果你想一次性修改大量内容，最方便的是修改 [scripts/seed.ts](scripts/seed.ts) 然后重新执行：

```bash
npx tsx scripts/seed.ts
```

这条命令会把分类、产品、文章重新写入数据库。

### 适合场景

- 新增分类
- 新增产品
- 新增推荐文章
- 更新文章标题和摘要
- 更新分类描述

## 8. 常见修改场景

### 修改首页展示的分类数量

在 [src/app/page.tsx](src/app/page.tsx) 中找到：

```tsx
take: 8
```

改成你想展示的数量。

### 修改首页展示的热门产品数量

同样在 [src/app/page.tsx](src/app/page.tsx) 中找到：

```tsx
take: 6
```

### 修改分类页显示的产品条数

在 [src/app/(directory)/[category]/page.tsx](src/app/(directory)/[category]/page.tsx) 中调整查询逻辑即可。

### 修改指南页显示哪些文章

在 [src/app/(content)/guide/page.tsx](src/app/(content)/guide/page.tsx) 中修改查询条件即可。

## 9. 推荐的修改顺序

最推荐的顺序是：

1. 先改页面文案：适合改首页、分类页、指南页的文字。
2. 再改数据库内容：适合增删分类、产品、文章。
3. 最后改 SEO 元信息：适合改标题和描述。

---

## 10. 最实用的操作建议

如果你只是想“手动改一下网站前端展示内容”，建议优先这样做：

- 想改页面上的文字：改组件文件。
- 想改分类/产品/文章内容：改数据库或种子脚本。
- 想快速新增内容：改 [scripts/seed.ts](scripts/seed.ts) 后重跑脚本。
