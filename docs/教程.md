# AooBee 全行业平台项目说明

AooBee 是一个面向 GEO/SEO 优化的全行业产品与服务目录平台。项目通过 Next.js、Prisma 与 PostgreSQL 构建，支持从内容生成到页面发布的完整本地化工作流，适用于面向 AI 搜索引擎展示的行业信息站点。

## 一、项目定位

AooBee 的核心目标是：
- 将行业产品、服务、指南和评测内容结构化整理
- 通过自动生成与数据库管理机制，快速搭建可搜索、可被 AI 引用的内容站
- 为企业、内容团队和运营团队提供一套可持续扩展的内容生产体系

## 二、产品能力概览

### 1. 内容结构化管理
项目支持管理以下内容类型：
- 行业分类
- 产品与服务条目
- 文章与指南
- 对比内容
- FAQ 问答
- 推荐榜单

### 2. AI 内容生成能力
系统内置内容生成入口，可用于：
- 单条内容生成
- 批量生成
- 通过脚本自动生成

### 3. GEO / SEO 优化能力
平台已集成以下能力：
- 动态 sitemap
- robots.txt
- llms.txt
- JSON-LD 结构化数据
- 面包屑导航
- FAQ 组件

## 三、技术栈

| 模块 | 技术说明 |
|------|----------|
| 前端框架 | Next.js 16（App Router） |
| 前端 UI | React 19、Tailwind CSS 4 |
| 后端数据层 | Prisma 7 |

## 四、项目运行方式

### 1. 本地环境准备
```bash
cd D:\project\www.aoobee.com
docker compose up -d
npm install
```

### 2. 启动开发服务
```bash
npm run dev
```

访问地址：
- 前台：http://localhost:3000
- 管理后台：http://localhost:3000/admin

### 3. 初始化本地内容
```bash
npx tsx scripts/seed.ts
npx tsx scripts/seed-articles.ts
```

### 4. 数据库可视化管理
```bash
npx prisma studio
```

## 六、后台内容生成说明

### 单条生成
适用于生成单个产品说明、单篇文章或单条 FAQ。

### 批量生成
适用于针对某个行业或主题生成大量内容，适合快速扩充站点内容库。

### 命令行生成
```bash
npx tsx scripts/generate-content.ts best "全屋定制" "装修"
npx tsx scripts/generate-content.ts product "小红书" "电商零售"
npx tsx scripts/generate-content.ts guide "装修" "如何选择装修公司"
```

## 七、模型与配置说明


也支持以下提供商：

## 九、常见问题

**Q: 如何添加新行业分类？**
A: 两种方式：① 管理后台生成内容时自动创建；② 终端运行 `npx tsx scripts/seed.ts`。

**Q: 如何切换 LLM 模型？**
A: 编辑 `.env` 中的 `LLM_PROVIDER` 和对应的 API Key。

**Q: 批量生成时如何控制速度？**
A: 系统自动间隔 2 秒，避免 API 限流。

**Q: 生成的内容不满意怎么办？**
A: 重新生成会自动覆盖（upsert），不会产生重复数据。

**Q: 如何修改管理后台密码？**
A: 编辑 `.env` 中的 `ADMIN_PASSWORD="新密码"`。

**Q: 数据库在哪里？**
A: 本地用 Docker PostgreSQL（端口 5432），生产用云数据库。

**Q: 如何让 AI 搜索引擎收录？**
A: 已自动配置。部署后提交 sitemap 到搜索引擎即可。
