# AooBee 全行业平台 使用教程

---

## 一、项目概览

AooBee 是一个 **GEO-SEO 优化的全行业产品目录平台**，通过 LLM 大模型批量生成结构化内容，方便 AI 搜索引擎（ChatGPT、Perplexity、Google AI Overview 等）抓取和引用。

### 技术栈
| 组件 | 技术 |
|------|------|
| 前端框架 | Next.js 16 (App Router) |
| 样式 | Tailwind CSS 4 |
| 数据库 | PostgreSQL 16 (Docker) |
| ORM | Prisma 7 |
| LLM | 多模型支持（MiMo / DeepSeek / OpenAI 等） |

### 当前数据规模
- **10 个行业分类**（人工智能、软件开发、电商零售、数字营销、设计创意、企业管理、教育培训、金融科技、装修、旅游）
- **34 个产品** + **137 条评价**
- **23+ 篇文章**（指南、对比、推荐、评测、FAQ）

## 二、本地启动

### 1. 启动数据库
```bash
cd D:\project\www.aoobee.com
docker compose up -d
```

### 2. 启动开发服务器
```bash
npm run dev
# 访问 http://localhost:3000
```

```bash

```

---

### 方式一：单条生成

适合：生成单个产品、单篇文章

**操作步骤：**
1. 点击「单条生成」标签
2. 选择内容类型（产品描述 / 产品对比 / 行业指南 / 推荐榜单 / FAQ问答）
3. 填写信息（产品名、行业等）
4. 点击「生成内容」→ 右侧预览
5. 点击「保存入库」→ 前台立即可见

---

### 方式二：批量生成（推荐）

适合：针对某个行业或主题，一次性生成大量 SEO/GEO 内容

**操作步骤：**
1. 点击「批量生成」标签
2. 选择内容类型
3. 输入行业分类（如：装修）
4. 在文本框输入关键词（一行一个）
5. 点击「开始批量生成」
6. 右侧实时显示进度（✅ 成功 / ❌ 失败）

**示例：批量覆盖装修行业**

内容类型选「推荐榜单」，行业填「装修」，关键词输入：
```
全屋定制
装修公司推荐
装修预算
装修材料选购
装修避坑指南
小户型装修
```

点击「开始批量生成」，系统自动：
- 逐条调用 MiMo 生成内容
- 每条自动入库
- 前台立即可见

**各类型关键词格式：**

| 类型 | 关键词输入格式 | 示例 |
|------|--------------|------|
| 产品描述 | 产品名 | ChatGPT、小红书 |
| 产品对比 | 产品A vs 产品B | ChatGPT vs DeepSeek |
| 行业指南 | 主题 | 如何选择装修公司 |
| 推荐榜单 | 关键词 | AI写作工具、CRM系统 |
| FAQ问答 | 主题 | 装修注意事项 |

## 五、LLM 多模型配置

编辑 `.env` 文件，修改 `LLM_PROVIDER` 即可切换模型：

```bash
# 小米 MiMo（当前使用）
LLM_PROVIDER="mimo"
MIMO_API_KEY="your-key"

# DeepSeek（性价比最高）
LLM_PROVIDER="deepseek"
DEEPSEEK_API_KEY="your-key"

# OpenAI
LLM_PROVIDER="openai"
OPENAI_API_KEY="your-key"

# Claude
LLM_PROVIDER="anthropic"
ANTHROPIC_API_KEY="your-key"

# 通义千问
LLM_PROVIDER="qwen"
DASHSCOPE_API_KEY="your-key"

# 本地 Ollama（免费）
LLM_PROVIDER="ollama"
```

**支持的模型：**

| 提供商 | Provider 值 | 默认模型 |
|--------|------------|---------|
| OpenAI | openai | gpt-4o |
| Anthropic | anthropic | claude-sonnet-4 |
| DeepSeek | deepseek | deepseek-chat |
| 通义千问 | qwen | qwen-plus |
| 智谱GLM | zhipu | glm-4-plus |
| Kimi | moonshot | moonshot-v1-128k |
| 小米MiMo | mimo | mimo-v2.5-pro |
| Ollama | ollama | llama3.1 |
| 自定义 | custom | 自定义 |

## 九、常见问题

**Q: 如何添加新行业分类？**
A: 两种方式：① 管理后台生成内容时自动创建；② 终端运行 `npx tsx scripts/seed.ts`。

**Q: 如何切换 LLM 模型？**
A: 编辑 `.env` 中的 `LLM_PROVIDER` 和对应的 API Key。

**Q: 批量生成时如何控制速度？**
A: 系统自动间隔 2 秒，避免 API 限流。

**Q: 生成的内容不满意怎么办？**
A: 重新生成会自动覆盖（upsert），不会产生重复数据。

**Q: 如何修改管理后台密码？**
A: 编辑 `.env` 中的 `ADMIN_PASSWORD="新密码"`。

**Q: 数据库在哪里？**
A: 本地用 Docker PostgreSQL（端口 5432），生产用云数据库。

**Q: 如何让 AI 搜索引擎收录？**
A: 已自动配置。部署后提交 sitemap 到搜索引擎即可。
